# 机械原理简答题背诵计划 · 艾宾浩斯版

考研专业课《机械原理》简答题背诵工具。**329 题**，按教材章节分 **9 部分 / 50 个考点**，内置艾宾浩斯遗忘曲线复习排程。纯静态单文件网页，双击即开，无需后端、无需联网。

> 题库整理自求臻 2026 版《机械原理简答题背诵版》（题目 + 答案合订），仅作个人复习使用。

## 直接使用

打开 `index.html` 即可。数据保存在浏览器 `localStorage`，不上传服务器。

也可以部署到 GitHub Pages：Settings → Pages → Source 选 `Deploy from a branch` → `main` / `root`，之后访问 `https://<用户名>.github.io/<仓库名>/`。

## 功能

| 模块 | 说明 |
|---|---|
| 今日背诵 | **到期复习由系统按遗忘曲线自动加入**；**新题由自己「加入今日」**，互不干扰 |
| 艾宾浩斯 | 间隔 1 / 2 / 4 / 7 / 15 / 30 / 60 天；记得→进下一档，模糊→次日重来，忘记→回第 1 档 |
| 题库 | 9 部分 / 50 考点，可按章节下拉筛选、关键词搜索（题干 + 考点 + 答案） |
| 一键显示全部答案 | 只对当前筛选结果生效，不会把 329 条全铺开 |
| 答案可编辑 | 每题可写自己的版本，标注「我的版本」，可一键恢复原文 |
| 收藏 | ★ 收藏，列表内**默认置顶** |
| 已掌握 | 标记后退出复习队列，不再占用每日任务 |
| 答题卡 | 右侧悬浮卡，329 个题号一格一个；背过＝绿，已掌握＝深绿，点题号直接开该题 |
| 打卡 | 任务清空自动打卡，连续天数 + 10 周热力图 + 未来 7 天复习量预测 |
| 专注模式 | 一题一屏，先想再翻；`空格` 翻答案，`1` 记得 / `2` 模糊 / `3` 忘记 |
| 倒计时 | 距 2026-12-19（初试首场 8:30）还有 X 天 零 Y 小时，实时走字；日期可在设置里改 |
| 数据 | 设置页导出 / 导入 JSON，换设备或清浏览器前先备份 |

**冷门考点单独存放**（60 题）：默认不进每日计划、不进复习队列，只在题库里单列；想背可在设置里开启，或单题「加入今日」。

## 文件

```
index.html   单文件站点（含全部题目、答案、配图与样式脚本，离线可用）
data.json    题库数据（329 题，便于二次开发或做别的客户端）
```

```jsonc
  ]

```

## 说明

- 题目与答案由扫描件经 MinerU OCR 识别后整理，3 道题（第 138、228、243 题）题干在 OCR 中丢失，已对照原页手工补齐；其余文本未改写，仅做了删广告行、合并断行等清洗。
- 公式用自写的轻量 LaTeX 解析器渲染（支持 `\frac`、`\sqrt`、上下标、希腊字母、`\vec` 等），不依赖 MathJax/KaTeX，保证离线可用。
- 进度只存在本机浏览器，**手机和电脑不互通**；需要多端同步得另接云数据库。
